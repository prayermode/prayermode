Two Ways to Install Prayer mode

Prayer mode is available through two trusted channels. Choose the one that works best for you:

Option Best for Update method
F-Droid Users who prefer automatic updates from a trusted open‑source repository Automatic (through F-Droid)
Direct APK Users who want the latest version immediately or don't use F-Droid Manual (check website for updates)

Security Note

Verified & Safe: Both the F-Droid repository and the APK on this website are built from the exact same open‑source code. You can verify the APK signature against the GitHub release if you wish.

Option 1: Install via F-Droid

F-Droid is a trusted, open‑source app store that only contains free and open‑source software. Prayer mode is available in the official F-Droid repository.

1 Install F-Droid from f-droid.org if you don't have it yet.

2 Open F-Droid and search for "Prayer mode".

3 Tap Install and grant any requested permissions.

4 Once installed, updates will be delivered automatically through F-Droid.

Note: Prayer mode is available in the main F-Droid repository – no additional repository is needed. If you still can't find it, try refreshing the repository list in F-Droid (Settings → Repositories → Refresh).

Option 2: Install Directly from Our Website (APK)

If you prefer to install the APK directly, follow these steps.

Step 1: Enable "Install from Unknown Sources"

Security Notice: This is a standard Android security feature. You only need to enable this temporarily to install Prayer mode. We recommend turning it off again after installation.

Since Prayer mode is distributed outside the Google Play Store, you need to allow your browser or file manager to install apps. The steps vary by Android version:

For Android 7.0

1 Go to Settings

2 Select Security

3 Enable Unknown sources

4 Confirm any security warning

For Android 8.0 to Android 12

1 Open Settings

2 Tap Apps & notifications

3 Select Advanced → Special app access

4 Tap Install unknown apps

5 Select the app you're using to download (e.g., Chrome, your file manager)

6 Toggle Allow from this source to ON

For Android 13 and later

1 Open Settings

2 Go to Apps

3 Select Special app access

4 Tap Install unknown apps

5 Choose your browser or file manager

6 Enable Allow from this source

For Xiaomi / MIUI devices

1 Open Settings → Apps → Manage apps

2 Tap the ⋮ menu and select Settings → Install unknown apps

3 Select your browser or file manager → enable Allow

Step 2: Download and Install the APK

1 Go to the Home page and download the latest APK.

2 Open the downloaded file (usually in your Downloads folder).

3 Tap Install and confirm any security prompt.

4 Once installation is complete, tap Open to launch Prayer mode.

Step 3: Disable Unknown Sources (Recommended)

After installing, return to the same settings and toggle Allow from this source back to OFF for security.

After Installation

Once Prayer mode is installed, we recommend:

  • Granting the necessary permissions when prompted (location, notifications, DND access)
  • Setting your preferred calculation method in the app settings
  • Configuring per‑prayer settings (durations, Ablution, Iqama) to your preference

Verifying APK Authenticity

For maximum security, you can verify that the APK matches the official GitHub release:

  • Download the APK from GitHub Releases
  • Check the SHA‑256 hash against the one published on the release page
  • Compare the signature using tools like apksigner

Troubleshooting

"App not installed as package appears to be invalid"

  • Uninstall any existing version of Prayer mode first
  • Make sure you're using the latest APK
  • Try downloading the APK again (the file may be corrupted)

"Install" button is greyed out / "Blocked by Play Protect"

  • Tap More details → Install anyway
  • If Play Protect blocks it, you can temporarily disable it in Google Play Store → Play Protect settings
